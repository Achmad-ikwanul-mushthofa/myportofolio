# Portofolio Achmad

React + TypeScript + Three.js + Tailwind CSS v4 + AOS.

## Run
npm install
npm run dev

## Edit data
Open `src/data/site.ts` to edit profile, technologies, projects and certificates.

## Replace images
- Profile: `public/images/profile.jpg`
- Projects: `public/projects/`
- Certificates: `public/certificates/`

Project/certificate image paths are configured in `src/data/site.ts`.

## Add CV
Put your PDF at `public/Achmad-Ikwanul-Mushthofa-CV.pdf`.
